# Refine the task

Capture outcome, exact scope, acceptance criteria, constraints and minimum
checks. Reuse information already given; do not paraphrase a clear request back
at length. Ask only about ambiguity that changes the implementation. Carry the
refined scope into worker briefs and the saved Claude audit plan. Preserve all
existing user authorization; refinement does not add a confirmation gate.
