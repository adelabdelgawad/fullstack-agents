# Fullstack Agents 3.81.0

- Dark RetroUI Agents and History with the original workspace organization, compact three-line summary cards, Codex balance on the first line, and contained card actions.
- Distinct `/next/agents`, `/next/herdr`, and `/next/history` URLs with direct loading, refresh, and browser navigation.
- RetroUI Orchestrators, Information, Git changes, inner cards, and usage metrics.
- Task evidence supports `scope.worktree` for registered linked checkouts of the same repository. Checks and fingerprints use that checkout while the ledger keeps its existing location and owner.
- Clearer worker-return instructions: resolve the worker blocker with its result, clear the execution lease, and verify before completing the deliverable.

Existing evidence specs retain their behavior. To use a linked worktree, accept an updated spec with its absolute `scope.worktree` path and rerun required checks. This release does not infer completion from task notes or merge application branches.

After updating the Codex plugin, review its changed hooks in `/hooks`: select an event (SessionStart, UserPromptSubmit, PostToolUse, or Stop) to see the Fullstack Agents entry. Plugin updates may require renewed trust.

Validation: 295 task lifecycle tests, 92 Codex integration tests, 4 packaging tests, 115 dashboard frontend tests and 25 dashboard HTTP tests passed. Local diff review completed. The external Claude audit was not run because automatic approval review rejected the source transfer.
